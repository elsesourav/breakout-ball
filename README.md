## 🚀 Key Features

### 1. ⚡ Deterministic C++ WebAssembly Physics Engine
- **Microsecond Collision Loops**: Continuous collision integration that completely eliminates "tunneling" at high ball velocities.
- **Spin Dynamics & Angle Deflection**: Dynamic launch trajectories calculated from paddle contact velocity and offset vectors.
- **Zero-GC Stutter**: Pre-allocated memory structures maintain perfectly fluid 60/120 FPS frame rates without garbage collection hiccups.

### 2. 🪐 100 Campaign Sectors Across 10 Themed Cyber Worlds
- **10 Distinct Worlds**: Neo-Tokyo, Quantum Core, Neon Cyberpunk, Bio-Hazard, Molten Core, Deep Abyss, Solaris Flare, Chrono Glitch, Celestial Void, and Omega Singularity.
- **Progressive Mechanics**: Unbreakable shielding, EMP pulse generators, quantum warp portals, health-scaled armor bricks, multi-ball clusters, and explosive chain reactions.
- **Intelligent Map Positioning**: Automatically restores and scrolls to the player's active campaign sector upon loading or returning from victory.

### 3. 🛠️ In-Browser Level Designer Studio
- **Matrix Grid Canvas**: Full interactive editor with multi-tile brushes, fill tools, eraser, and color pickers.
- **12+ Block Types**: Normal, Reinforced, Steel, Explosive, Multi-Ball, EMP, Laser, Portal, and Shield blocks.
- **Instant Cloud Publishing**: Test any level in a sandbox emulator and publish it to the community gallery with one click.

### 4. 🌐 Real-Time Apex Global Arena
- **Live Leaderboard**: Cross-device global rankings with microsecond speedrun timers and 3-star rating tiers.
- **Daily Apex Challenges**: Automated daily competition seeds with exclusive leaderboard trophies.
- **Robust Cloud API**: High-availability Fastify + Supabase backend hosted at `https://api-breakout.elsesourav.com`.

### 5. 🛡️ Cyber Armory & Visual Customizations
- **Signature Paddles**: Equip high-tech hulls like the *Valkyrie Horizon*, *Quantum Strike*, and *Obsidian Aegis*.
- **Energy Balls & VFX**: Choose between *Plasma Core*, *Solar Flare*, *Inferno*, and *Cosmic Void* ball trails.
- **Coupon & Promo Engine**: Redeem promotional codes for exclusive cyber cosmetics and core currency.

### 6. 🎮 Universal Multi-Input Controls
- **Touch & Swipe**: Ultra-responsive fluid touch controls tailored for mobile browsers and PWA.
- **Keyboard & Mouse**: Arrow keys, A/D, and smooth mouse paddle tracking with aiming guideline projection.
- **Gyroscope Tilt & Gamepad API**: Real hardware tilt navigation and analog gamepad support with haptic vibration feedback.

### 7. 🔐 Seamless OAuth & Cross-Tab Multi-Window Sync
- **Google & GitHub SSO**: Native OAuth popup support on desktop and mobile web with automatic cross-tab state propagation via `BroadcastChannel` and storage synchronization.
- **Encrypted Local Fallback**: Full offline play support with automatic sync upon reconnecting.

## 🛠️ Local Development & Setup

### Prerequisites
- **Node.js** >= 18.0.0
- **npm** or **pnpm**
- **Python 3** (with `Pillow` and `numpy` for asset generation scripts)

### Installation
```bash
# Clone the repository
git clone https://github.com/elsesourav/breakout-ball.git
cd breakout-ball

# Install dependencies
npm install

# Start Vite local development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production
```bash
# Typecheck and build production bundle
npm run build

# Preview production build locally
npm run preview
```

### Running Backend API (Optional)
```bash
# Start local Fastify API server (port 4000)
npm run server
```
*Note: The client automatically defaults to the production cloud API at `https://api-breakout.elsesourav.com` when running locally without a custom backend.*

### Regenerating Showcase Assets
```bash
# 1. Capture 4K desktop and retina mobile screenshots
node scripts/capture_live_screenshots.mjs

# 2. Capture animated gameplay frames and compile GIFs
node scripts/capture_live_gifs.mjs
python3 scripts/compile_gifs.py

# 3. Generate all ElseSourav banners, covers, and app icons
python3 scripts/generate_showcase_assets.py
```
